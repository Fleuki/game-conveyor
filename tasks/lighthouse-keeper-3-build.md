## Что сделано
`games/lighthouse-keeper/`:

| Файл | Что внутри |
|------|-----------|
| index.html | canvas, блокировка скролла/выделения/контекстного меню, `/sdk.js`, модуль main.js |
| config.js | все константы баланса и раскладки поля |
| game.js | логика ночи без DOM (общая для игры и симулятора) |
| sim.js | симулятор баланса: `node sim.js [ночей]` |
| main.js | порядок запуска, экраны, ввод, пауза, реклама |
| ya.js | обёртка Yandex Games SDK + заглушка для локального запуска |
| save.js | сохранение: облако SDK + localStorage |
| i18n.js | строки RU/EN |
| audio.js | Web Audio: синтез эффектов, музыка из assets/music/ |
| render.js | отрисовка моря, кораблей, луча и темноты |
| assets/img/ | 11 спрайтов из поставки GPT |

Экраны: загрузка (неинтерактивная), меню с улучшениями, игра с обучением на первом корабле, пауза, итоги ночи.

Обёртка SDK названа `ya.js`, а не `sdk.js`: Яндекс раздаёт свой SDK как `/sdk.js` из корня игры, и одноимённый
файл в корне архива его подменил бы.

Отладка: `index.html?debug` открывает `window.__game` (состояние, кнопки, сохранение) — только для автотестов.

- убывание курса растёт со временем: `1 + 0.003 × секунды`;
- запас курса: лодка 8, шхуна 10, пароход 12 с; скорость шхуны 34, парохода 26 px/с;
- цены улучшений: 15 / 35 / 70 / 120 / 180.

## Проверки
- Chromium (Playwright), подменённый SDK: порядок `init → lang → getData → ready`; `GameplayAPI.start/stop` на старте,
  паузе, возобновлении, конце ночи; «Продолжить — за рекламу» даёт 1 жизнь и продолжает ночь; «×2 монеты» удваивает
  (5 → 10) и убирает «Продолжить»; interstitial только со 2-й ночи сессии при выходе с экрана итогов;
  облачное сохранение пишется; улучшение нельзя купить без монет.
- Локальный запуск без SDK: ошибок и неудачных запросов в консоли нет.
- `document.querySelectorAll('audio, video').length === 0`.
- Язык: `<title>` и интерфейс — «Lighthouse Keeper» при lang=en, «Смотритель маяка» при ru.
- Скриншоты меню, обучения, игры, паузы и итогов просмотрены на 390×780; меню EN на 1280×720.
