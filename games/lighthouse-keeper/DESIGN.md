# Смотритель маяка — дизайн-документ

Название и slug — в `GAME_NAME.md`. Вертикальный экран 9:16 в приоритете, логическое поле 360×640,
на широких экранах поле центрируется, по бокам — продолжение фона моря.

## Core loop
1. Ночь начинается: маяк внизу по центру, над ним тёмное море, у нижнего края — причал (гавань).
2. Корабли появляются у верхнего края и плывут вниз к гавани.
3. У каждого корабля кольцо «курса». Вне луча оно убывает, в луче — восполняется.
4. Кольцо опустело — корабль сбивается с курса и разбивается о скалы (−1 фонарь-жизнь).
5. Корабль дошёл до гавани — +1 к счёту и монеты.
6. Со временем корабли идут чаще, появляются крупные и туман. 3 крушения — ночь окончена.
7. Экран итогов → монеты на улучшения → новая ночь.

Целевая длина ночи: 2–4 минуты у среднего игрока.

## Управление
- Один палец: касание или ведение пальцем по экрану — луч поворачивается к точке касания
  с ограниченной скоростью поворота. Отпустил палец — луч остаётся где был.
- Мышь на ПК — то же самое (ведение с зажатой кнопкой или просто движение курсора).
- Больше никаких жестов. Понятно без обучения: первые 10 секунд — один медленный корабль
  и подсказка-рука «веди лучом».

## Корабли и помехи
| Тип | Появляется | Скорость | Запас курса | Монеты |
|-----|-----------|----------|-------------|--------|
| лодка | с начала | быстрая | малый | 1 |
| шхуна | со 2-го спасённого десятка | средняя | средний | 2 |
| пароход | с 3-го десятка | медленная | большой | 3 |

- Туман: полупрозрачное пятно, дрейфует; корабль в тумане восполняет курс вдвое медленнее.
- Скалы: декорация по краям моря; крушение показывается у ближайшей скалы.

## Прогрессия
- Валюта — монеты, копятся между ночами.
- Улучшения маяка (по 5 уровней каждое):
  - **Линза** — ширина луча;
  - **Лампа** — скорость восполнения курса;
  - **Механизм** — скорость поворота луча.
- Рекорд: больше всего кораблей, спасённых за одну ночь.
- Цели на экране меню: «спаси 25 / 50 / 100 за ночь» — отметки-звёзды у рекорда.

## Экраны
- **Меню:** название, кнопка «Играть», рекорд, монеты, панель улучшений (три строки: уровень,
  цена, кнопка «Улучшить»), переключатель звука.
- **Игра:** поле, сверху счёт спасённых, три фонаря-жизни, монеты за ночь, кнопка паузы.
- **Пауза:** «Продолжить», «Заново», «В меню», звук вкл/выкл. Игра и звук останавливаются;
  при сворачивании вкладки пауза включается сама.
- **Проигрыш (итоги ночи):** спасено, рекорд (отметка «новый рекорд»), монеты за ночь,
  «Продолжить за рекламу» (1 раз за ночь), «×2 монеты за рекламу», «Ещё ночь», «В меню».

## Что сохраняется
Через данные игрока SDK, с локальным резервом:
- монеты;
- уровни трёх улучшений;
- рекорд за ночь и полученные отметки-звёзды;
- всего спасено кораблей (для статистики);
- настройка звука;
- флаг «обучение пройдено».

## Реклама
- **Interstitial:** только между ночами — при нажатии «Ещё ночь» или «В меню» на экране итогов,
  начиная со второй ночи сессии. Никогда во время игры. Звук на время показа выключается.
- **Rewarded:**
  - «Продолжить» — восстановить 1 фонарь-жизнь и доиграть ночь (1 раз за ночь);
  - «×2 монеты» — удвоить монеты за ночь на экране итогов.
  Награда выдаётся только после колбэка о полном просмотре.

## Баланс — черновик, проверить симулятором
Все числа ниже — стартовые, до прогона симулятора на этапе 3. В коде живут только в `config.js`.

| Параметр | Значение |
|----------|----------|
| Жизни (фонари) | 3 |
| Интервал появления кораблей: старт / минимум | 3,0 с / 1,1 с |
| Сокращение интервала за спасённый корабль | 0,05 с |
| Скорость: лодка / шхуна / пароход | 45 / 32 / 22 px/с |
| Запас курса: лодка / шхуна / пароход | 5 / 7 / 9 с |
| Восполнение курса в луче | ×3 к скорости убывания |
| Ширина луча, уровень 0 → 5 | 18° → 34° (+3,2° за уровень) |
| Длина луча | 560 px |
| Скорость поворота луча, уровень 0 → 5 | 150 → 300 °/с |
| Восполнение (Лампа), уровень 0 → 5 | ×3 → ×5,5 (+0,5 за уровень) |
| Цены улучшений, уровни 1–5 | 20 / 45 / 90 / 160 / 250 монет |
| Туман | с 40-го спасённого, не больше 2 пятен |

Ожидания для симулятора: новичок без улучшений — 15–30 кораблей за ночь (2–3 мин);
с улучшениями 3/3/3 — 50–70 кораблей (3–5 мин); полная прокачка — за 10–15 ночей.

## Визуал
- Настроение: спокойная, уютная ночь; холодное тёмное море и тёплый золотой свет маяка.
  Контраст «тьма — свет» и есть главная картинка игры.
- Палитра:
  - `#0B1B2B` — ночное небо, самый тёмный фон;
  - `#16384A` — глубокое море;
  - `#2E6F7A` — волны, блики воды;
  - `#FFD27A` — луч и свет маяка;
  - `#F29E4C` — фонари, огни кораблей, акценты интерфейса;
  - `#E8F1F2` — пена, текст, белые детали.
- Ориентиры: ночная акварельная иллюстрация к морской сказке; плоская векторная графика
  с мягкими градиентами; открытка «вечерний рыбацкий порт».
- Вид: море сверху; корабли сверху, нос вниз. Луч, волны, свечение, туманная дымка
  частично рисуются кодом (градиенты Canvas).

## Звуки (только CC0, .wav)
Источники: библиотеки с лицензией CC0 — наборы Kenney (раздел Audio), OpenGameArt с фильтром CC0,
Freesound с фильтром лицензии Creative Commons 0. Лицензию каждого файла записать на этапе 3.

| Звук | Где |
|------|-----|
| щелчок интерфейса | кнопки |
| колокол / рында | корабль вошёл в гавань |
| треск дерева | крушение |
| гудок парохода | появление парохода |
| монета | начисление монет, покупка улучшения |
| шум волн (петля) | фон во время ночи |
| мягкий аккорд / колокольчик | новый рекорд |
| низкий глухой удар | конец ночи |
