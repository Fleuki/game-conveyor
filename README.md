# game-conveyor — конвейер HTML5-игр Fleuki

Репозиторий, в котором игры для Яндекс.Игр проходят путь от идеи до публикации.
Стек игр: чистый JavaScript (ES-модули), Canvas 2D, Web Audio API. Без npm, сборщиков и зависимостей.

Работа идёт этапами (idea → assets → build → check → store → upload → moderation → live),
описание — в `docs/stages.md`. Каждый этап выполняет отдельная сессия, поэтому всё состояние
хранится в файлах: общая таблица — `STATUS.md`, задачи — `tasks/`, игры — `games/<slug>/`.

Участники:
- Claude — идеи, код, проверки, материалы страницы (правила: `CLAUDE.md`, команда `/next`);
- ChatGPT — изображения по заказам из `handoff/gpt/requests/` (правила: `AGENTS.md`);
- человек — загрузка в консоль при необходимости и отправка на модерацию.

Правила площадки — `docs/platform/yandex-games.md`.
