# Этапы конвейера

Каждая игра проходит этапы по порядку. Текущий этап и от кого он зависит — в `STATUS.md`.
Одна сессия Claude выполняет ровно один этап одной игры.

| № | Этап | Исполнитель |
|---|------|-------------|
| 1 | idea | claude |
| 2 | assets | gpt |
| 3 | build | claude |
| 4 | check | claude |
| 5 | store | claude |
| 6 | upload | claude (только локально, с браузером) |
| 7 | moderation | человек |
| 8 | live | claude + человек |

## 1 idea
- **Исполнитель:** claude.
- **Вход:** список уже сделанных игр, ограничения из запроса, `docs/platform/yandex-games.md`.
- **Выход:** `games/<slug>/IDEAS.md` (3 идеи с оценками), `games/<slug>/GAME_NAME.md`,
  `games/<slug>/DESIGN.md`, `handoff/gpt/requests/<slug>-assets.md`, `tasks/<slug>-2-assets.md`,
  строка игры в `STATUS.md`.
- **Готово, когда:** все файлы созданы, заказ для GPT самодостаточен, в `STATUS.md` этап 2, ждёт gpt.

## 2 assets
- **Исполнитель:** gpt (человек переносит заказ в ChatGPT и кладёт результат в репозиторий).
- **Вход:** `handoff/gpt/requests/<slug>-assets.md`.
- **Выход:** `handoff/gpt/deliveries/<slug>/*.png` и `handoff/gpt/deliveries/<slug>/manifest.md`.
- **Готово, когда:** все файлы из заказа лежат в папке поставки с правильными именами и размерами,
  есть `manifest.md`. Следующая сессия Claude сверяет поставку с заказом и переводит игру на этап 3.

## 3 build
- **Исполнитель:** claude.
- **Вход:** `DESIGN.md`, `GAME_NAME.md`, поставка из `handoff/gpt/deliveries/<slug>/`, CC0-звуки (.wav).
- **Выход:** `games/<slug>/` — `index.html`, ES-модули, `config.js` (все константы баланса),
  симулятор баланса, `assets/` (картинки и звуки), `tasks/<slug>-3-build.md` с итогом.
- **Готово, когда:** игра запускается локально, core loop, все экраны из DESIGN.md, сохранение
  прогресса и реклама через SDK работают; прогон симулятора процитирован в задаче.

## 4 check
- **Исполнитель:** claude.
- **Вход:** собранная игра, `docs/platform/yandex-games.md`.
- **Выход:** `tasks/<slug>-4-check.md` — чек-лист правил площадки с результатом по каждому пункту
  (как проверено, вывод), исправления в коде.
- **Готово, когда:** все пункты чек-листа пройдены (нет `<audio>/<video>`, порядок SDK, язык из SDK,
  блокировка скролла, только .wav, единое название и т.д.).

## 5 store
- **Исполнитель:** claude.
- **Вход:** проверенная игра, `GAME_NAME.md`, иконка и обложка из поставки GPT.
- **Выход:** `games/<slug>/store/` — описания RU/EN (краткое и полное), скриншоты, снятые из самой
  игры, `tasks/<slug>-5-store.md`.
- **Готово, когда:** тексты используют название ровно как в `GAME_NAME.md`, скриншоты сняты из
  реальной игры в нужных ориентациях и размерах.

## 6 upload
- **Исполнитель:** claude, только в локальной сессии с доступом к браузеру. В облачной сессии — пропустить.
- **Вход:** архив игры, материалы из `store/`; человек уже вошёл в консоль Яндекс.Игр.
- **Выход:** заполненный черновик в консоли разработчика, `tasks/<slug>-6-upload.md` с перечнем
  заполненных полей.
- **Готово, когда:** черновик сохранён, все поля заполнены. «Отправить на модерацию» НЕ нажимать.
  Пароли, ключи, платёжные данные не вводить.

## 7 moderation
- **Исполнитель:** человек.
- **Вход:** черновик в консоли.
- **Выход:** игра отправлена на модерацию; результат (замечания или одобрение) записан
  в `tasks/<slug>-7-moderation.md`.
- **Готово, когда:** модерация пройдена. При замечаниях игра возвращается на этап 3 или 4.

## 8 live
- **Исполнитель:** claude + человек (человек выгружает статистику из консоли).
- **Вход:** опубликованная игра, статистика (удержание, длина сессии, возвраты).
- **Выход:** `tasks/<slug>-8-live.md` — сводка метрик и предложения по улучшению.
- **Готово, когда:** сводка записана; изменения баланса — только через симулятор (см. `CLAUDE.md`).
