# Яндекс.Игры — правила модерации

- Элементы <audio>/<video> запрещены. Проверка: document.querySelectorAll('audio, video').length === 0
- Скролл блокируется через position: fixed + preventDefault на touchmove.
- Порядок SDK строго: init → язык из SDK → загрузка ассетов → ready() → включение ввода.
- ready() вызывается до того, как игра становится интерактивной.
- Язык определяется только через SDK, не хардкодом.
- .ogg не использовать (Safari/iOS), только .wav.
- Одно каноническое название на игру, фиксируется в GAME_NAME.md. Везде одинаково:
  поля консоли, описания, обложка, иконка. Названия капсом запрещены. Транслит вместо
  перевода запрещён (RU и EN — отдельные нормальные названия).
- Раздел «Новое» не даёт трафика. Решают удержание, длина сессии, возвраты.

## ПРОВЕРИТЬ ПО ДОКУМЕНТАЦИИ ЯНДЕКСА

Числа ниже ориентировочные, это не точные требования — проверить по документации Яндекса
перед этапами 2 (заказ картинок) и 5 (скриншоты).

- Иконка: около 512×512.
- Обложка: около 800×470.
- Скриншоты: размеры и количество для вертикальной и горизонтальной ориентации — уточнить.
